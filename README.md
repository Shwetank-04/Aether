# AETHER

AETHER is a lightweight hybrid virtual instrument created by Club $V.

## Goals

- Lightweight CPU usage
- Professional interface
- Original synthesis engine
- Original modeled instruments
- Modern preset browser
- Expandable factory library

## Planned Categories

- Pianos
- Keys
- Electric Guitars
- Acoustic Guitars
- Nylon Guitars
- Pads
- Strings
- Bass
- Synths
- FX

## Roadmap

### v0.1
- Plugin framework
- Engine foundation
- GUI foundation

### v0.5
- Synth engine
- ADSR
- Filters
- Polyphony

### v1.0
- Factory library
- Original instruments
- Professional GUI
